# Portfolio item

**Title:** AI support assistant in Next.js: grounded answers, no exposed keys

**Role:** Developer

**Description:** Support answers need reliable sources and protected credentials. I built a help-center assistant that retrieves FAQ entries, streams answers and shows expandable sources. A browser-only simulation powers the public demo; a separate server route protects credentials and adds validation, timeouts and request limits. Unit and browser tests cover answers, unsupported questions, failures and responsive behavior.

**Skills:** React, Next.js, TypeScript, OpenAI API, Unit Testing
